# Production Analysis Scripts

This folder contains the figure and table scripts used for the manuscript-facing BehaviorScope-X v9 analyses.

Scripts in this folder are organized around the reported manuscript outputs:

- MARS YOLO/SPPF temporal classifiers and classical baselines
- MARS MobileNetV3 backbone portability
- DLC-HRNet top-down route
- descriptor provenance analyses
- Fly-v-Fly focused attention-256 short-bout evaluation
- GUI/deployment supplement material

Generated CSV/JSON verification files are retained under `verification_files/by_experiment/00_manuscript_tables`.
