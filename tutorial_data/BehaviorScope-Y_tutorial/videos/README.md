# Tutorial Videos

The MP4 files for this tutorial are distributed separately from the Git repository because regular GitHub repositories block files larger than 100 MiB.

After downloading or copying the tutorial media package, this folder should contain:

- `train/*.mp4`
- `val/*.mp4`
- `test/*.mp4`

The GUI menu action `Tutorial > Download/Load BehaviorScope-X tutorial...` will download the tutorial from Hugging Face, or ask you to locate the tutorial data folder if you already downloaded it manually.
